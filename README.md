# legal-lab-media

Медиафайлы для Instagram @legal.lab.ai (карусели, Reels, обложки) и шаблоны их сборки.

- `posts/` — карусели, `reels/` — ролики, `covers/` — обложки Reels
- `tools/render_carousel.py` — карусель из JSON
- `tools/make_reel.py` — Reels: золотая обложка + слайды + музыка
- `tools/music_neoclassic.py` — оригинальная неоклассическая музыка (генерируется кодом)
